# OpenLayers Route Map App

A small front-end web application built as part of a technical assessment. The project was developed using **HTML, CSS, and JavaScript** and uses **OpenLayers** to display an interactive world map and visualize routes between selected locations.

## Demo

Click on the map to add locations, manage them in the sidebar, and generate routes between selected points.

## Features

- Interactive world map using OpenLayers
- Add locations by clicking on the map or manually entering coordinates
- Select and deselect locations
- Drag and drop to reorder locations
- Rename or delete locations
- Visual route drawing between selected points
- Right-click to remove map pins
- Sidebar interface for managing all locations
- Basic input validation for manual coordinates

## How it works

- Each click on the map adds a location pin
- Locations are stored in a JavaScript array and synced with the UI list
- Selected locations are used to generate a route line on the map
- Routes are drawn using OpenLayers vector layers

## Tech Stack

- HTML
- CSS
- JavaScript
- OpenLayers

## Notes

This project was created as a technical assessment/demo and focuses on front-end logic, map interaction, and DOM manipulation.
